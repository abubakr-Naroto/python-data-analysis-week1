# Student Expenses Analysis

مشروع تدريبي للأسبوع الأول من مادة مدخل إلى تحليل البيانات.

## وصف المشروع
تحليل مصروفات طالب جامعي خلال أسبوعين
باستخدام Python وPandas.

## ملفات المشروع
- data/expenses.csv : البيانات التجريبية
- notebooks/expenses_analysis.ipynb : دفاتر التحليل
- project_plan.md : خطة المشروع
- expenses_chart.png : 2D chart generated from the notebook
- requirements.txt : مكتبات Python

## طريقة التشغيل
1. إنشاء بيئة Python افتراضية وتفعيلها.
2. تثبيت المكتبات: `python -m pip install -r requirements.txt`.
3. تشغيل JupyterLab من داخل مجلد المشروع: `jupyter lab`.
4. فتح دفتر التحليل وتنفيذ الخلايا بالترتيب.

## ملاحظة
